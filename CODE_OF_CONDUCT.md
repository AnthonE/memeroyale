# Code of conduct

Meme Royale is a game about memes. Keep it fun.

- Be kind and assume good intent. Critique the code, not the person.
- No harassment, slurs, sexual content, or personal attacks, here or toward other players.
- Don't share anyone's personal information.
- Maintainers may edit or remove comments, close issues and pull requests, and block people who break these rules.

To report a problem privately, use **Security → Report a vulnerability** on this repository (only the maintainers see
it) and say it's a conduct report. You can also use GitHub's own **Report content** button on any comment.

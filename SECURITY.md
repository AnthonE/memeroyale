# Security

## Report privately

Found a way to crash the server, cheat, take over a lobby, or see another player's information? **Don't open a
public issue.** Use **Security → Report a vulnerability** on this repository's GitHub page. Only the maintainers can
see it.

Please tell us what you found, how to reproduce it, and what someone could do with it. We'll acknowledge your report
within a week, and we'll credit you in the release notes unless you'd rather we didn't.

## What counts

- **In scope:** crashing the server, cheats the server accepts, taking over an admin session or a lobby, and reading
  another player's details or address.
- **Out of scope:** flooding your own server, and bugs that only affect a practice match against bots.

## Test on your own copy

Run your own server (`npm run server`, or see [HOSTING.md](HOSTING.md)) and test against that. Don't test against the
live game or its players. Good-faith research on your own copy, reported privately, will never be pursued.
